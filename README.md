Project Overview
This repository contains three basic web development projects created using HTML5 and external CSS3. The projects demonstrate webpage structure, navigation, responsive layouts, CSS Grid, cards, and tables.
Task 1: Electronics Store Website
Objective: Develop an online electronics catalog for laptops, smartphones, accessories, and smart devices.

Features:
- Product categories and navigation links
- Product cards with specifications and discount labels
- Product comparison table
- Product prices and detail links
- Responsive layout using CSS Grid and media queries
Files: index.html, style.css
Task 2: Digital Library Management Interface
Objective: Design a library website to display books, authors, categories, and availability.

Features:
- Book categories and book-cover images
- Book titles, author details, and availability labels
- Search and filter interface elements
- Structured catalog table
- Library rules section
- Responsive book cards using CSS Grid
Files: index.html, style.css
Task 3: Healthy Food and Nutrition Website
Objective: Build a website presenting nutritious recipes, meal plans, ingredients, and healthy eating tips.

Features:
- Food categories such as salads, fruits, vegetables, and breakfast
- Responsive recipe cards with images
- Ingredient lists and preparation times
- Approximate calories per serving
- Sample daily meal-plan table
- Healthy eating tips
Files: index.html, style.css
Technologies Used
- HTML5: Page structure and content
- CSS3: Styling, layout, colors, and responsive design
- CSS Grid: Responsive cards and category layouts
- HTML Tables: Product comparisons, book catalog, and meal plans
- Media Queries: Adapt layouts for mobile and desktop screens
How to Run
1. Download or clone this repository.
2. Open the folder for the project you want to view.
3. Ensure index.html and style.css are in the same folder.
4. Open index.html in a web browser.
Brief Notes
- These are front-end demonstration projects; they do not include a database or server-side functionality.
- Search, filter, and detail links are interface examples unless JavaScript or backend functionality is added.
- Product details and prices are sample data.
- Recipe calorie values are approximate and vary by ingredients and serving sizes.
- Some images use online placeholder URLs and require an internet connection.
Learning Outcomes
- Create structured webpages with semantic HTML.
- Apply external CSS to style websites.
- Build responsive layouts using CSS Grid and media queries.
- Present information clearly using cards, labels, and tables.
- Organize project files for GitHub.
